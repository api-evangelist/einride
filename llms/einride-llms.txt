# Einride Extend (Saga) API

> Einride Extend is the open API and developer-tools layer for Saga, Einride's freight
> mobility platform for electric and autonomous road freight. The resource-oriented APIs
> (designed with Google AIP) let you book truck tours and create/track shipments over both
> gRPC and HTTP. The APIs are alpha (v1beta1) and available to select developers during an
> early-access phase. Authentication is a Bearer token obtained by exchanging a client ID +
> client secret. Root address: https://api.saga.einride.tech (regional: eu./us.).

## APIs
- [Authentication API](openapi/einride-auth-openapi-original.yml): Exchange a client ID/secret for a short-lived bearer access token.
- [Shipment & Booking API](openapi/einride-book-openapi-original.yml): Create, list, update, release and cancel shipments; create, confirm, search and cancel truck tours.
